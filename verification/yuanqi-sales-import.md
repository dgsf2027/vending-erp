# 元气森林销售表导入验证

2026-11-09

销售通道直接展示元气森林销售文件的10列表头。上传保留原列顺序和原值，内部仍映射到既有销售字段；可跳过表头前的标题。预览增加整表订单数、数量、实收、优惠券、日期范围、商品和机器数，以及商品编码匹配列表。缺失机器与格式问题在确认前提示，页面阻止提交并支持重新核对档案。手机预览正文滚动，确认按钮保留在窗口内。

订单时间为业务时间，支付金额为该行实收，单价由金额除以数量计算；优惠券只供核对，不加入实收。保留既有一单多行和同文件重复导入规则、确认事务、别名匹配及YQ自动编号。预览不创建商品、别名或销售；未修改历史数据或数据库结构。

验证：

- 30项后端测试通过（SalesProductAutoCreateTest、ExcelParserTest、ProductCatalogMatcherTest），包含标题行、原始表头、只读预览、别名沿用YQ编码、缺失机器、错误行、重新核对，以及原有并发和事务回滚。
- 用户提供的销售附件在隔离H2库中实际上传和确认：3403行、2903个订单、25个商品名、10台机器；数量3816、实收16896.49。全部导入，无失败或待绑定；重复导入跳过3403行，金额及数量不增加。测试通过系统属性vend.test.salesFile读取本地附件，不提交业务文件。
- 前端类型检查、生产构建通过。
- yuanqi_sales_import.cjs通过7组页面检查；import_channel_pages.cjs通过5组原有通道回归。预览、商品匹配、确认、缺失机器后的重新核对、错误行阻止提交、手机按钮可见及无横向溢出均通过。
- 页面截图位于frontend/.vite/yuanqi-sales-qa，使用本地模拟API，无线上数据写入。

范围限制：商品匹配沿用现有档案和别名；本次不在生产环境导入销售，也不合并生产商品档案。重复导入验证针对同一完整文件，未更改既有订单行编号算法。
